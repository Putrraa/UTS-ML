Delapan baris pertama dataset. Kolom target pada file asli bernilai 0 untuk pasien penyakit jantung dan 1 untuk yang sehat; di aplikasi ini nilainya dibalik agar 1 berarti penyakit jantung.

Preprocessing

  1. Cek missing value. Ditemukan {{ info.missing_value }} nilai kosong, jadi tidak ada baris yang dibuang karena hal ini.
  2. Hapus duplikat. {{ info.duplikat }} baris duplikat dihapus, tersisa {{ info.jumlah_baris_akhir }} baris.
  3. Balik label target. Kelas penyakit jantung dijadikan kelas positif (1) supaya precision dan recall bermakna secara medis.
  4. Tanpa scaling. Decision Tree membagi data berdasarkan ambang nilai, sehingga skala fitur tidak memengaruhi hasil.
  5. Bagi data. {{ info.data_training }} data training dan {{ info.data_testing }} data testing (80:20), dibagi stratified agar proporsi kelas terjaga.
